=== scripts/mcp_client.py proof — driving two existing MCP servers via the shared harness ===

### CLI: list-tools ###
$ python3 scripts/mcp_client.py list-tools tools/secure-random/server.py

### CLI: call (single tool, single-shot) ###
$ python3 scripts/mcp_client.py call tools/secure-random/server.py roll_dice '{"notation": "2d6+3"}'
--- roll_dice ---
{
  "notation": "2d6+3",
  "rolls": [
    4,
    5
  ],
  "modifier": 3,
  "total": 12
}

### CLI: call, deliberately invalid input -- surfaces as a real MCP tool error, not a crash ###
$ python3 scripts/mcp_client.py call tools/secure-random/server.py roll_dice '{"notation": "garbage"}'
--- roll_dice ---
ERROR: Error executing tool roll_dice
(exit code: 1, nonzero as expected for a single failed call)
